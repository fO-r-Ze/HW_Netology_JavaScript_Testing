# Credit Card Validator

![Deploy](https://github.com/fO-r-Ze/HW_Netology_JavaScript_Testing/actions/workflows/deploy.yml/badge.svg?branch=main)
[GitHub Pages](https://fO-r-Ze.github.io/HW_Netology_JavaScript_Testing/)

Виджет проверки номера банковской карты (алгоритм Луна) с определением платёжной системы.

## Что реализовано

- Luhn-валидация номера
- Определение платёжной системы: Visa, Mastercard, American Express, Мир, Union Pay, Discover, JCB, Diners Club
- Автоопределение системы по мере ввода (обновление логотипа)
- Unit-тесты валидатора и определения системы (`jest`)
- JSDOM-тесты взаимодействия с виджетом через `jest.each`
- e2e-тесты через Puppeteer (валидный и невалидный ввод)

## Скрипты

- `yarn start` — dev-сервер (`http://localhost:8080`)
- `yarn build` — production-сборка в `dist/`
- `yarn test` — unit- и JSDOM-тесты
- `yarn test:e2e` — Puppeteer-тесты (требует запущенный `http://localhost:9000`)
- `yarn test:all` — собирает сервер на 9000 и запускает e2e
- `yarn lint` — ESLint

## CI

При пуше в `main` GitHub Actions:
1. Устанавливает зависимости
2. Прогоняет линтер
3. Прогоняет unit- и JSDOM-тесты
4. Собирает production-сборку
5. Поднимает `dist` на 9000 и прогоняет Puppeteer
6. Публикует `dist` на GitHub Pages

### Credit Card Validator

#### Легенда

Вам пришла задача: сделать виджет, позволяющий вводить номер карты (можете в качестве общего развития почитать про PCI DSS).

Общий вид виджета должен выглядеть следующим образом:

![](./pic/validator.png)

Вам нужно провести исследовательскую работу и выяснить - на базе чего определяется, какой платёжной системе принадлежит определённая карта (не забудьте про "Мир").

#### Описание

Используйте [следующий алгоритм](https://en.wikipedia.org/wiki/Luhn_algorithm) для проверки валидности номера карты.

Изображения для карт необходимо найти самостоятельно (помните, про авторские права и недопустимость нелегального использования). 

Разделите логику проверки номера карты, выяснения принадлежности определённой платёжной системе и взаимодействия с DOM.

Напишите авто-тесты на функции проверки номера карты и принадлежности определённой платёжной системе.

В качестве источника номеров карт используйте сервис [FreeFormatter](https://www.freeformatter.com/credit-card-number-generator-validator.html).

Удостоверьтесь, что всё работает при прогоне тестов в GitHub Actions.
